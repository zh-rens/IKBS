# 欲望与身份：性取向议题中的生物基底与话语建构

一直以来我搞不明白一个事情：同性恋究竟是与生俱来、恒定不变的本质属性？还是社会塑造的产物，即性认同是可以被话语、环境甚至舆论凭空制造？也许关键在于搞清楚生物学因素和社会话语在这里面扮演着怎样的角色。

在社会建构论中，福柯曾经对现代性谱系进行考察。19 世纪之前，欧洲法律与宗教规制的是**鸡奸（男男肛交）这一类行为**，行为者不会被视作一类特殊的人。行为可以被惩戒，但不会被解读为根植于人格、童年与内在本性的特质。直到十九世纪精神病学、司法体系共同完成了一次概念革命：不再仅仅审判行为，而是诊断人。“同性恋者” 的概念由此诞生，它不再只是一次越轨举动，而是一整套拥有生命史、病理特征的人格类型。

这一话语发明自带深刻的内在矛盾。医学话语最初目的是以病理学之名对这类群体进行污名与规训，将其定义为反常的变体；但恰恰是这套命名体系，第一次给了这类体验一个可供言说的词汇。被用来定罪、病理化的语言，反过来成为抗争的武器：人们借用这套话语，主张自身欲望的自然性，争取承认与合法性，即同性恋是个人的纯粹生理本能，你不能以此给我定罪或者将我视为异类。于是同性恋身份呈现出悖论式的双重属性：它既是权力压迫的产物，也是群体身份政治赖以生长的资源。

跨文化的历史材料进一步瓦解了本质主义的预设。古希腊的情欲秩序，以年龄、社会阶层、性行为中的角色为轴心组织，而非以对象性别划分性取向。一个成年公民可以同时拥有对女性、少年的亲密关系，在当时的认知框架中并不构成矛盾。现代社会以 “异性恋 / 同性恋” 二元划分人格的分类方式，是近代才形成的认知框架，无法直接套用到前现代文明之中。这说明：**同性的情欲体验可以跨文化存在，但 “同性恋” 作为一种稳定、定义人的本质身份，是特定时代话语的产物。** 本质主义的困境正在于此，它假设存在一套跨越时空、统一的 “性取向” 人格，却忽视不同文明组织情欲的底层逻辑完全不同。

但承认身份的社会历史性，不等于走向另一个极端 —— 否定欲望存在稳定的生物学倾向。社会建构论解释 “身份如何被命名”，却无法解释一个统计事实：同性欲望的分布并非完全随机，在不同时代、不同人群中保持着可观测的稳定趋势。生物学研究提供的并非一个决定论式的答案，而是概率性的基底图景。

性取向属于多基因复杂性状，不存在单一的 “同性恋基因”，众多基因位点各自产生微弱效应，累加后塑造倾向，无法用来精准预判个体。神经解剖层面的研究发现，性取向和大脑性二态结构存在相关性，但相关性不等于因果。大脑结构既不是单向 “决定” 欲望的原因，也不是欲望带来的简单结果，二者是胚胎发育同一过程的并行产物。综合这些证据，生物学给出的结论应当审慎：它划定的是**欲望倾向的概率分布**，而非锁定个体的最终命运。生物因素打开可能性区间，却不能敲定一个人的身份标签。

女性性流动性研究，为弥合生物基底与社会建构之间的裂隙提供了关键支点。Lisa Diamond 长期追踪研究显示，不少女性的情欲与依恋不是被锁死在异性恋、同性恋的二元分类里，会随着生命阶段、亲密关系对象发生变动。传统刚性的性取向模型大量建立在男性样本之上，低估了女性欲望的情境敏感性。这种流动性，不是外部洗脑的结果，而是欲望本身存在的性别差异。

至此，我们可以厘清二者的分工：生物学塑造欲望可能性的分布形态；社会话语改变的是**体验被看见、被命名、被接纳的门槛与代价**。社会环境不会无中生有制造欲望，但是当个体本就具备流动的情欲空间时，一套新的身份词汇、社群叙事，就可以帮助个体命名原本模糊、难以言说的内在体验。

这一结论会引来一种反驳：既然欲望存在流动性，是否意味着性认同可以被外部环境、社群叙事刻意诱导甚至操控？即，此时此刻你的性认同并非由你决定的，而更多是环境的影响。原生家庭创伤、性别议题叙事、算法茧房，似乎构成一条完整链条，用以塑造出新的性认同。

我们来假设这样一个女性，早年父母离异，长大后经历过异性恋结果被背叛，同时经常看的抖音小红书里充斥着女权，厌男物料，这是否会导致她倾向于同性恋爱？

### 🏠 原生家庭：情感安全模式的底色

如果父母早年离异，首先塑造的是她对亲密关系“安全性”的底层判断。原生家庭是个人情感经验和社会化的最初场所。在一个异性恋婚姻破裂的环境中成长，她可能比同龄人更早、更切身地体验到：**以异性恋为核心的家庭结构，本身是脆弱的、可被摧毁的。**

但这本身并不“导致”同性恋——它更可能产生两种效果：一种是对异性恋亲密关系模式的**不信任与防御**；另一种是，当她在别处（比如女性友谊、女权社群）找到更稳定的情感认同时，原生家庭的经历会让她**更愿意将这种认同视为“真正的安全”**，而不是必须回到那个曾让她受伤的异性恋框架里去。

### 📢 “厌男”与政治女同性恋：情感与政治的交汇

她的“厌男”言论和“女性互助”叙事，在社会理论中有两个精确的对应。

### 总结

生理因素不决定一个人的性认同，但它以概率方式影响欲望倾向的分布和认同移动的可能性；环境不制造欲望，但改变体验被命名、被表达、被选择的空间。性认同是倾向分布、生命事件、话语可见性和具体关系对象之间的接合。也许我们不需要去判断她是“真的”还是“被影响的”——在社会理论的视角下，**所有的性认同都是在某种话语与关系的配置中被组装出来的**，异性恋的认同同样如此，只是它的组装过程太过默认，以至于我们从不追问它是怎么来的。
