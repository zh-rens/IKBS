# 静电：身边看不见的"小闪电"

静电，顾名思义，是"静止的电荷"。它不像插座里的电流那样持续流动，而是悄悄积累在物体表面，等待某一个瞬间突然释放。别看它平时不起眼，生活中几乎处处都有它的身影。

## 一、静电是怎么来的？

两个物体相互摩擦（或仅仅紧密接触再分开）时，束缚力弱的电子会"跳槽"到束缚力强的物体上。于是：

- **失去电子的一方带正电**
- **得到电子的一方带负电**

电荷积累之后无法流动，就停在那里——这就是静电。

静电特别钟爱的季节是**冬天**：空气干燥、衣物厚重、摩擦频繁，再加上皮肤干燥电阻大，电荷越攒越多，电压可高达几千甚至上万伏。好在电量极小，只够"啪"地麻你一下，伤不了人。

## 二、生活中的静电案例

### 1. 脱毛衣的"噼啪"交响曲

冬天晚上脱毛衣，黑暗里常能看到蓝色小火花，还伴随细碎的噼啪声。这是毛衣和内衣摩擦积累的静电在纤维间放电。如果周围有易燃气体，这种小火花就可能酿成大祸，所以加油站严禁拍打衣物。

### 2. 头发"炸毛"与梳子吸纸屑

用塑料梳子梳头，头发会越梳越"飘"，甚至根根竖起互相排斥（同性电荷相斥）。更神奇的是，梳过头的梳子能吸起小纸屑——带电物体可以吸引轻小物体，这也是验电器的工作原理。

### 3. 开门把手被"电"一下

人走动时，鞋底与地毯、身体与化纤衣物反复接触、分离。由于不同材料对电子的束缚能力不同，电子经摩擦起电持续转移到人体，使人体积累多余的电子而带负电；又因鞋底与衣物是绝缘体，电荷无法泄漏，便在人体上不断积累，形成很高的对地电压。

当手指逐渐接近接地的金属门把手时，人体电场使把手靠近手指的一端感应出正电荷；同时，根据尖端效应，人体表面电荷在曲率最大的指尖处密度最大、场强最强。

当场强超过空气的击穿场强（约 3 kV/mm）时，空气被电离，形成等离子体放电通道——即火花放电，伴随声响与刺痛。若改用手掌大面积接触墙面或金属，电荷可在击穿发生前经较大接触面缓慢分散泄漏，从而避免火花放电。

### 5. 静电喷涂

给汽车喷漆时，让漆雾带电、车身带相反电荷，油漆会自动"飞"向车身均匀附着。这样喷漆均匀、省料，还减少污染。

### 6. 油罐车尾的"小尾巴"

运输汽油的油罐车尾部常拖着一条铁链拖地。这是为了把行驶中油液晃动、摩擦产生的静电持续导入大地，防止静电积累放电引燃油蒸气。飞机加油、油轮装卸也都有类似的接地要求。

### 7. 电子厂里的"防静电服"

芯片内部的电路只有几纳米宽，一点点静电就能把它击穿报废。所以电子厂工人要穿防静电服、戴手环，车间还要保持一定湿度，"小心静电"是行业的头等大事。

## 三、静电的两面性

| 有益的静电         | 有害的静电                   |
| ------------------ | ---------------------------- |
| 复印、打印、喷涂   | 引燃加油站、面粉厂的火灾爆炸 |
| 除尘、空气净化     | 击穿芯片，损坏电子产品       |
| 静电植绒、静电分选 | 干扰精密仪器运行             |

## 四、结语

静电是电子的"小规模搬家"：平时安分守己地积累，释放时却干脆利落。它既能帮我们复印文件、净化空气，也能在加油站里露出危险的一面。理解它的脾气——知道电荷从哪来、往哪去——就能在冬天少挨几下"电击"，也多一分安全意识。

下次脱毛衣"噼啪"作响时，不妨想想：那是一场发生在衣服上的、只有几纳秒的微型闪电。
